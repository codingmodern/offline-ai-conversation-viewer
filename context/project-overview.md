## 2. Project Objective

### Goal
ساخت یک اپلیکیشن وب کاملاً آفلاین که فایل‌های JSON خروجی‌گرفته‌شده از پلتفرم‌های مختلف AI Chat را باز، شناسایی و با ظاهر اصیل (Authentic UI) همان پلتفرم نمایش می‌دهد.

### Problem Statement
کاربرانی که مکالمات خود با ابزارهای AI مختلف را Export می‌کنند، معمولاً فایل JSON خام و بی‌ساختار در اختیار دارند که به‌سختی قابل مرور است و هیچ شباهتی به تجربه‌ی بصری اصلی پلتفرم ندارد. کاربر باید بتواند این آرشیو را مثل یک کتابخانه‌ی شخصی مرور کند، بدون نیاز به آپلود در هیچ سروری.

### Target Users
- کاربرانی که مکالمات AI خود را برای آرشیو، مستندسازی یا مرور مجدد Export می‌کنند.
- کاربرانی که به دلایل حریم خصوصی نمی‌خواهند فایل‌های Export‌شده را در هیچ سرویس آنلاینی آپلود کنند.

### Value Proposition
تبدیل یک فایل JSON خام به یک تجربه‌ی بصری آشنا و اصیل — بدون بک‌اند، بدون آپلود، بدون اینترنت. بازتولید وفادارانه‌ی تجربه‌ی کاربری هر پلتفرم، بدون هیچ وابستگی به کد یا زیرساخت رسمی همان محصولات.

---

## 3. Core User Flow

1. کاربر یک یا چند فایل JSON (خروجی ChatGPT / Claude / Gemini / DeepSeek) را از طریق File Picker یا Drag & Drop باز می‌کند.
2. اپلیکیشن فرمت فایل را Validate و پلتفرم مبدا را **به‌طور کاملاً خودکار** (بدون هیچ انتخاب دستی از سوی کاربر) Detect می‌کند.
3. فایل Parse شده و به کتابخانه‌ی محلی (Local Library) اضافه می‌شود؛ این کتابخانه در IndexedDB ذخیره می‌شود تا بین بازدیدها باقی بماند.
4. مکالمه در Sidebar کتابخانه ظاهر می‌شود و کاربر می‌تواند بین چند مکالمه/فایل ذخیره‌شده جابه‌جا شود.
5. با انتخاب یک مکالمه، محتوا با تم اختصاصی همان پلتفرم (Layout، رنگ، فونت، حباب‌های چت، آیکون‌ها) و متادیتای مربوطه رندر می‌شود.
6. کاربر می‌تواند در محتوای مکالمات (باز شده) جستجو کند.

## 5. Scope

### In Scope
- Import و Parse فایل‌های JSON از ۴ پلتفرم (ChatGPT, Claude, Gemini, DeepSeek)
- تشخیص کاملاً خودکار پلتفرم (بدون دخالت کاربر)
- معماری Parser ماژولار و قابل‌توسعه برای پلتفرم‌های آینده
- رندر اختصاصی هر پلتفرم (تم مجزا) — مستقل از کد/Asset رسمی محصولات
- نمایش متادیتای مکالمه (در صورت وجود در فایل)
- کتابخانه‌ی محلی چند‌مکالمه‌ای با Persistence (IndexedDB)
- جستجوی متنی درون مکالمات

### Out of Scope
- ویرایش یا ارسال پیام جدید (اپ فقط Viewer است، نه Chat Client)
- Export مجدد یا تبدیل فرمت
- هرگونه ارتباط با سرور، API یا اینترنت
- احراز هویت یا حساب کاربری
- پشتیبانی از فرمت‌های غیر JSON (HTML, ZIP) — در فاز اول
- انتخاب یا تغییر دستی پلتفرم توسط کاربر

## 6. Success Criteria

1. کاربر می‌تواند یک فایل JSON از هر یک از ۴ پلتفرم را باز کند و آن به‌طور کاملاً خودکار شناسایی و رندر شود، بدون هیچ انتخاب دستی.
2. افزودن پشتیبانی از یک پلتفرم جدید در آینده، بدون تغییر در Parserها یا منطق Detection پلتفرم‌های موجود ممکن باشد.
3. چند فایل هم‌زمان در کتابخانه ذخیره می‌شوند و بعد از بستن/باز کردن مرورگر باقی می‌مانند.
4. تم بصری هر پلتفرم قابل‌تشخیص، متمایز از بقیه، و مستقل از کد/Asset رسمی است.
5. متادیتای موجود در فایل (عنوان، تاریخ، تعداد پیام، مدل) به‌درستی نمایش داده می‌شود.
6. جستجو در مکالمات باز‌شده نتیجه‌ی صحیح برمی‌گرداند.
7. اپلیکیشن بدون هیچ درخواست شبکه‌ای (Network Request) کار می‌کند.
