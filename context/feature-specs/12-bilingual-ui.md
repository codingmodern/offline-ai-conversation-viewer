# Spec: Unit 12 — دوزبانه‌سازی UI (Persian/English i18n)

## Goal

افزودن پشتیبانی چندزبانه به UI برنامه با `react-i18next`، شروع با فارسی و انگلیسی، به‌گونه‌ای که افزودن زبان‌های بعدی فقط نیازمند فایل ترجمه‌ی جدید باشه — بدون تغییر منطق.

## User Flow

1. کاربر برای اولین بار برنامه رو باز می‌کنه → صفحه‌ی انتخاب زبان (Language Onboarding) نمایش داده می‌شه.
2. کاربر بین فارسی/English با toggle انتخاب می‌کنه.
3. انتخاب ذخیره می‌شه (`localStorage`) → جهت صفحه (RTL/LTR) و زبان UI اعمال می‌شه → کاربر وارد اپ اصلی می‌شه.
4. در بازدیدهای بعدی، زبان ذخیره‌شده مستقیم اعمال می‌شه (onboarding دوباره نشون داده نمی‌شه).
5. کاربر هر زمان از تنظیمات می‌تونه زبان رو عوض کنه.

## Functional Requirements

- نصب و پیکربندی `react-i18next` + `i18next`
- فایل‌های ترجمه: `locales/en/common.json`، `locales/fa/common.json`
- صفحه‌ی Language Onboarding (فقط بار اول)
- Language Switcher در تنظیمات/هدر برای تغییر بعدی
- تمام متن‌های استاتیک UI (منو، دکمه، پیام خطا، empty state، tooltip) از طریق `t()` بیان بشن
- ذخیره‌ی انتخاب در `localStorage` (کلید مشخص، مثلاً `app-language`)
- تنظیم خودکار `dir="rtl"` یا `dir="ltr"` روی `<html>` بر اساس زبان UI

## Non-functional Requirements

- بدون وابستگی به شبکه (فایل‌های ترجمه باید local/bundled باشن، نه CDN)
- تغییر زبان بدون reload کامل صفحه (فوری)
- Bundle size اضافه‌شده باید minimal باشه

## UI Behavior

- Toggle در صفحه‌ی onboarding: مدرن، دو گزینه (فارسی | English)، انتخاب فعلی highlight بشه
- تغییر جهت صفحه لحظه‌ای و بدون پرش/flicker بصری
- Language Switcher در تنظیمات هم از همون کامپوننت toggle استفاده کنه

## Validation

- اگه `localStorage` خراب/نامعتبر بود → fallback به انگلیسی + نمایش onboarding

## Edge Cases

- کاربری که onboarding رو نیمه‌کاره رها کنه و صفحه رو ببنده → دفعه‌ی بعد onboarding دوباره نشون داده بشه
- زبان مرورگر تأثیری در تصمیم نداره (طبق تصمیم قبلی، فقط انتخاب صریح کاربر)
- محتوای چت‌های import‌شده (RTL/LTR per-message) کاملاً مستقل از این سیستم می‌مونه، دست‌نخورده باقی می‌مونه

## Acceptance Criteria

- [ ] بار اول باز کردن اپ → onboarding نمایش داده می‌شه
- [ ] انتخاب زبان → کل UI (منو، دکمه، پیام‌ها) به همون زبان + جهت صحیح نمایش داده می‌شه
- [ ] رفرش صفحه → onboarding دیگه نشون داده نمی‌شه، زبان قبلی حفظ می‌شه
- [ ] تغییر زبان از تنظیمات → آنی و بدون reload اعمال می‌شه
- [ ] محتوای چت‌های وارد‌شده تحت تأثیر تغییر زبان UI قرار نمی‌گیره
